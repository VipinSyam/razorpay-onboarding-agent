How the agent works

Rules make every decision that can harm a merchant. AI only reads messy notes and writes messages. Nothing is sent without a human.

Rule: diagnose→ AI: read unclear note→ Rule: accept or escalate→ Rule: route, priority, channel→ AI: write message→ Check: up to 11 safety checks→ AI: rewrite once if failed→ Human: approve

Assumptions (what-if)

Change a number and every rule-based column and total updates instantly. Messages already written are not rewritten; re-run the agent to refresh them.
